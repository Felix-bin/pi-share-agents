## 连续任务流轮（f1–f4，2026-10-05，commandcode 供应商）

赛题任务模型是"彼此关联的连续任务"，单发基准无前轮可复用——为给记忆/编排机制一个
被设计针对的舞台，runner 增加 `--flow revisit`（SWE-QA 前 5 题正跑 + 后 5 轮逐字重访，
storageRoot 跨轮持久使共享记忆真实累积），判分 `--revisit-mod 5`。

| 轮 | 配置 | 结论 |
|---|---|---|
| f1 | 无复杂度门 | 沿革：重访比 SYN 1.10 / ABNM 1.14——无门时记忆短路不发生 |
| f2 | 门控接线 v1（判定在计划末行） | 弃：[SYNAPSE result] 块保头不保尾，判定行不可见 |
| f3 | 判定改首行 | 弃：块蒸馏 KEY LINES 仍丢裸控制行（stage-result 后修复） |
| f4 | 块摘要携带首行（stage-result 修复）+门生效 | 采用（下表） |

**f4 终版（10 轮全矩阵，token 均值 / 质量）**：

| 臂 | 首过 r1-5 | 重访 r6-10 | 重访/首过 | 质量首/重 | simple 门触发轮 |
|---|---|---|---|---|---|
| SYN（全机制） | 129K / 74.4 | 130K / 73.4 | 1.01 | 74.4 / 73.4 | r2, r6 |
| ABNM（关记忆） | 137K / 75.8 | 130K / 74.2 | 0.95 | 75.8 / 74.2 | r1, r6, r7 |
| ABNC（关语料） | 133K / 77.2 | 128K / 74.2 | 0.96 | 77.2 / 74.2 | r1, r6, r7 |

f4 发现（如实）：
1. **复杂度门成为真实产品机制**：判定 simple 的轮次（共 8 轮，43–107K）均值 69K，对全流程轮
   （22 轮，87–204K）均值 154K 的比值 45%，**即省约 55%，且 simple 轮质量 84–94 不降**；这是 A 套提示词设计
   但 p50o 此前从未接线的行为，本次经 stage-result 首行控制位修复后真正生效。
2. **记忆的 token/质量边际在重访流上仍 ≈0**（SYN 1.01 vs ABNM 0.95）：门按任务简单性触发而
   非按召回触发（flash 相似度召回不能可靠浮出结论，SYN 仅 r6 由召回触发）；与 r17 单发负贡献、
   A 套"命中率↑但 token 不转化"三层一致——记忆的可证收益在检索命中率（74.7→97.8%）与复用
   计数（机制层），产品默认单发关记忆的决策不变。
3. f2/f3 两代失败=机制接线的真实工程教训（控制位必须随块可见），沿革留档。
