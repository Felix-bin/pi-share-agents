## 2. 最重要的事实：两批样本**不同分布**，原报告的数字是"更容易的子总体"上的估计

| 指标 | 原报告（前 240 轮，n=239） | 扩样（全 991 轮，n=990） |
|---|---|---|
| 基余弦 **均值** | 0.7187 | **0.6496** |
| 基余弦 < 0.8 的对数 | 194（81.2%） | **919（92.8%）** |
| rank-5/6 间隙 **中位** | 0.00550 | **0.00392** |
| 字面选点（256/int16/0.99）有序一致 | 58.16% | **46.77%** |
| 选定点（127/int8/0.99）有序一致 | 56.90% | **45.35%** |

**必须怎么读**：原报告 §5.3 的 56.9%（以及 top-1 97.9%、集合 79.1%）描述的是**前 240 轮这个子总体**，
不是这份语料的一般情形。在同一语料上把轮次走全，一致性降到 **45.4%**，基相似度均值从 0.72 降到 0.65、
排名间隙中位从 5.5e-3 降到 3.9e-3。
**任何材料引用旧数字时必须带"前 240 轮预留轮次子样本"这一限定，否则失真。**

## 3. 判定：悬念**不能**在可达样本量内关闭

扩样后的配对统计（字面最高档 256/int16/0.99 vs 选定点 127/int8/0.99）：

| 项 | 值 |
|---|---|
| 配对不一致 b : c | **128 : 114**（b = 只有字面档通过的对数） |
| 配对差 | **+1.41 pp** |
| McNemar 精确双侧检验 | **p = 0.403** |
| McNemar 95% CI | **[−1.66, +4.49] pp**（**含 0**） |
| 平均载荷 | 2529.98 B（256/int16） vs 1895.79 B（127/int8） |

**要把 1.41pp 的差异判到显著，需要 n ≈ 4680 对**。而本机制受**自身上限**约束：内存库
`SYNAPSE_DEFAULT_MAX_LOADED_RECORDS = 1000`，且 `list()` 在超限时**静默截断**——因此在本配置下
可录制的对数上限约 995（已用到 990）。**也就是说：这个效应量在本语料 + 本机制下永久低于分辨率下限。**

**对 D2 的意义（比原结论更强）**：原判据是"在 239 对分辨率下不可分"；现在是
**"在可达的最大样本（990 对）下仍不可分，且再扩样也不可达（需 4680 对，超出机制上限 4.7 倍）"**。
选定点（载荷较字面档少 25.1%、且有 int8 结构上界 3072 B < 4096 B 的保证）因此不再是"样本不足时的取舍"，
而是**在可判定范围内不可区分时的工程选择**。冻结常数**不变**（`delta-params.ts` 保持 127/int8/0.99）。

## 4. 扩样暴露的更重要事实：生产策略下残差**极少被触发**

P4-4 的发送侧策略是「载荷 > 半个完整向量 → 改发完整向量」（`SYNAPSE_DELTA_MAX_PAYLOAD_SHARE = 0.5`），
实测曲线把这条线划在基余弦约 0.85。

- 本语料 **92.8%** 的对（919/990）基余弦 **< 0.8**，即绝大多数情形发送侧**根本不会发残差**。
- 粗算触发率上限：基余弦 ≥ 0.8 的仅 71 对（**7.2%**）；按 0.85 分界则更低。

**连带结论**：① M8「非文本状态传递次数及数据规模」中 delta 一类会**很低**，材料里不得给出"普遍节省"的印象；
② 与全账负结果（P4-4 证据包 §五：载荷+两次基读取 1.44×、再加选基读取 60.9×）叠加，
delta 在本交付条件下的定位只能是**非默认机制 + 诚实边界**，与 K3 裁决 D4 的预登记一致。
